# LiveRelay

Aplicativo Android para retransmitir transmissões autorizadas da Twitch para o YouTube Live.

## Objetivos

* Interface simples para Android.
* Encaminhamento de vídeo e áudio sem salvar a transmissão completa no celular.
* Tentativa de manter a qualidade original quando compatível.
* Reconexão automática em caso de falhas.
* Funcionamento em segundo plano, respeitando as regras do Android.

## Estado do projeto

Em desenvolvimento. A transmissão real ainda precisa ser testada.

## Segurança

Nunca publique chaves de transmissão, senhas ou tokens neste repositório.
